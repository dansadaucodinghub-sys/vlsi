# Task - SystemVerilog

This folder covers the `task` - a routine that can contain timing and take input and output arguments.

## Files

| File | Description |
|---|---|
| `task.sv` | A `display_data` task that takes an address and data as inputs and prints them. It is called from an `initial` block with sample values. |

## Run

```bash
qverilog task.sv
```
