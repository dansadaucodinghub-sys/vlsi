# String - SystemVerilog

This folder covers the `string` type and its built-in methods and operators.

## Files

| File | Description |
|---|---|
| `string.sv` | Two strings are declared and then exercised with `len()`, `putc()`, `getc()`, `compare()` and `icompare()`, followed by the equality and relational operators (`==`, `!=`, `<=`, `>=`). |

## Run

```bash
qverilog string.sv
```
