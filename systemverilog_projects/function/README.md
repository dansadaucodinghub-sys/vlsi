# Function - SystemVerilog

This folder covers the `function` - a routine that runs in zero time and returns a value.

| File | Description |
|---|---|
| `function.sv` | A function that returns the sum of two numbers. |
| `void_function.sv` | A `void` function that returns nothing and is used only for its action (a display). |
| `automatic_function.sv` | An `automatic` function that calls itself (recursive factorial). |
| `function_output_args.sv` | A function that returns a value and also passes a result back through an output argument. |

## Run

```bash
qverilog <file>.sv
```
